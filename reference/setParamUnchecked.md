# Set a parameter UNCHECKED

Function for setting parameter values. THE OUTPUT IS NOT CHECKED FOR
VALIDITY!

## Usage

``` r
setParamUnchecked(object, name, value)

# S4 method for class 'Params'
setParamUnchecked(object, name, value)
```

## Arguments

- object:

  object to set parameter in.

- name:

  name of the parameter to set.

- value:

  value to set the parameter to.

## Value

Object with new parameter value.
