# Simulate gene means for splatPop

Simulate outlier expression factors for splatPop. Genes with an outlier
factor not equal to 1 are replaced with the median mean expression
multiplied by the outlier factor.

## Usage

``` r
splatPopSimGeneMeans(sim, params, base.means.gene)
```

## Arguments

- sim:

  SingleCellExperiment to add gene means to.

- params:

  SplatParams object with simulation parameters.

- base.means.gene:

  List of gene means for sample from matrix generated by
  `splatPopSimulateMeans` and with the sample specified in
  `splatPopSimulateSC`.

## Value

SingleCellExperiment with simulated gene means.
