# Add quantile normalized gene mean and cv info the eQTL key.

Add quantile normalized gene mean and cv info the eQTL key.

## Usage

``` r
splatPopQuantNormKey(key, means)
```

## Arguments

- key:

  Partial splatPop key data.frame.

- means:

  matrix or list of matrices containing means from `splatPopQuantNorm`

## Value

Final eQTL key.
